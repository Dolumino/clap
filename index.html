One-time setup

Connect the film catalog

Clap uses The Movie Database (TMDB) for posters, synopses and where each film is streaming. You need a free personal key.

  1. Create a free account on themoviedb.org.
  2. Open Settings → API and request a key. Choose “Developer” and describe it as a personal prototype.
  3. Copy the API Read Access Token (the long one) or the short API Key, and paste it below.
