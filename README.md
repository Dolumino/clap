# Clap

Find tonight's film without scrolling for hours. A personal prototype built on the TMDB API.

## Publish a change

1. Edit `index.html`.
2. Run `./bump.sh` (sets a new version number).
3. Commit and push. GitHub Pages updates within a minute or two; anyone with Clap open sees "New version available".

## First launch on a phone

Open the site link in Safari (iPhone) or Chrome (Android), add it to the home screen, open it from the icon, then paste the TMDB read access token once.

---
This product uses the TMDB API but is not endorsed or certified by TMDB. Streaming availability data is provided by JustWatch.
